该模块是 Next.js + react-notion-x 站点的顶层 UI 层，按职责拆分为若干独立组件：
- 页面容器：`NotionPage.tsx` 作为核心入口，组装 `PageHead`、`NotionPageHeader`、`PageAside`、`Footer`、`Utterances`，并通过 `notionRendererComponents` 注入自定义的 `nextImage`、`nextLink`、`Code`、`Collection`、`Equation`、`Pdf`、`Modal`、`Tweet` 以及属性渲染器（`propertyLastEditedTimeValue`、`propertyTextValue`、`propertyDateValue`）。
- 可选重型依赖通过 `next/dynamic` 按需加载并配合 `React.Suspense`（如 Code 语法高亮、PDF、Modal），避免首屏体积膨胀；`Collection` 与 `Pdf` 使用 `{ ssr: false }` 规避服务端/客户端 hydration 不一致。
- 全局弹窗 `SearchModal.tsx` 使用 `createPortal` 挂载到 `document.body`，从 `@/lib/config.api.searchIndex` 拉取本地搜索索引并按标签 AND 语义过滤。
- 通用 UI 原子：`Loading` / `LoadingIcon`（SVG 旋转指示器）、`ErrorPage`、`Page404`、`Footer`（`React.memo` 包裹）、`PageHead`（SEO meta）。样式统一走 CSS Modules（`styles.module.css`、`SearchModal.module.css`），并通过 `classnames` 组合动态类名。
- 依赖方向单向向下：组件仅依赖 `@/lib/*` 中的配置、类型与工具函数，不反向引用业务路由逻辑。
