模块按职责划分为若干平铺的 utility 文件，无子包：
- 配置层：`site-config.ts` 定义 `SiteConfig` 接口，`get-config-value.ts` 从根目录 `site.config.ts` 加载并允许 `NEXT_PUBLIC_SITE_CONFIG` 环境变量覆盖，`config.ts` 在此基础上派发出 `rootNotionPageId`、`domain`、`apiBaseUrl`、`pageUrlOverrides` 等全局常量。
- Notion 访问层：`notion-api.ts` 单例化 `notion-client` 的 `NotionAPI`（含重试、超时、User-Agent），`notion.ts` 在其之上实现带 60s TTL 的内存级 `ExtendedRecordMap` 缓存、导航页预取、collection query 修正、预览图与推文合并，并提供 `getPage`/`search` 两个对外入口。
- 页面解析管线：`resolve-notion-page.ts` 是核心编排器，依次处理 raw pageId → URL 覆盖 → URI→pageId 缓存 (`db.ts` 基于 `@keyvhq/core` 的 Keyv) → canonical map 查找 → 调用 `getPage` → 注入 ACL，最终产出 `PageProps`。
- 站点地图与路由：`get-site-map.ts` 通过 `notion-utils.getAllPagesInSpace` 扫描空间，过滤 `Public=false` 的页面，结合 `get-canonical-page-id.ts` 生成 `canonicalPageMap`；`map-page-url.ts`、`get-search-index.ts`、`get-social-image-url.ts`、`get-tweets.ts`、`oembed.ts`、`preview-images.ts`、`map-image-url.ts` 分别负责 URL 映射、搜索索引、社交图片、推文嵌入、OEmbed、LQIP 预览图等辅助功能。
- 类型与权限：`types.ts` 集中导出 `Site`、`PageProps`、`SiteMap`、`CanonicalPageMap` 等跨模块共享类型，`acl.ts` 根据 `rootNotionSpaceId` 校验页面所属工作区。
依赖方向单向：上层解析器依赖配置与 notion 封装，不反向被配置或底层 API 引用。
