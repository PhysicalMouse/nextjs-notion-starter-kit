- 站点配置统一通过 `getSiteConfig` / `getRequiredSiteConfig` 读取，缺失必填项时抛出 `Config error: ...` 错误。
- 对外部 API 调用（Notion、Twitter、OEmbed）使用 p-memoize 或内置 Map 做进程内缓存，避免重复网络请求。
- 所有 Notion 相关 ID 在入口处通过 `parsePageId` 规范化，无效 ID 直接抛错而非静默失败。
- 可选能力（预览图、搜索、analytics、clarity 等）均以布尔开关形式暴露到 `SiteConfig`，默认值由 `getSiteConfig(key, default)` 提供。
- 错误响应以 `{ message, statusCode }` 形式的 `PageError` 对象返回，由 `resolve-notion-page` 统一注入到 `PageProps.error`。
