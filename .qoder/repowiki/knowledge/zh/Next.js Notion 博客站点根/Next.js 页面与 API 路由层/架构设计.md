模块遵循 Next.js Pages Router 约定：
- 全局壳：`_app.tsx` 注入 `react-notion-x`、Prism、Fathom、PostHog、Vercel Analytics/SpeedInsights 等全局样式与埋点；`_document.tsx` 注入 Google/Bing 站点验证、favicon、manifest 及内联 dark-mode 脚本；`_error.tsx` 提供统一错误页。
- 页面路由：`index.tsx` 渲染根域名首页，`[pageId].tsx` 通过动态段匹配任意 Notion 子页面，两者均使用 `getStaticProps` + `resolveNotionPage(domain, pageId)` 获取数据并以 `revalidate: revalidateSeconds` 做增量静态再生成（ISR），`getStaticPaths` 在开发模式返回空路径以走 `blocking` 回退。
- 服务端生成页：`feed.tsx`、`sitemap.xml.tsx`、`robots.txt.tsx` 使用 `getServerSideProps` 直接写 `res` 输出 XML/RSS，并设置 `Cache-Control` 缓存头。
- API 路由（`pages/api/`）：`search-notion.ts`、`search-index.ts`、`indexnow.ts` 为传统 Node API；`social-image.tsx` 声明 `runtime = 'edge'`，用 `next/og` 的 `ImageResponse` 结合 Satori 渲染 OG 图片，并通过 `notion-api` 拉取 Notion 数据。
- 依赖方向单向向下：所有页面/API 仅消费 `@/lib/*`（config、notion、resolve-notion-page、get-site-map、types 等），不反向引用组件以外的业务逻辑。
