- 页面数据获取统一通过 `resolveNotionPage` 或 `getSiteMap` 从 `@/lib` 拉取 Notion 数据，再交给 `<NotionPage>` 渲染，避免在页面中直接调用 Notion SDK。
- 需要增量的静态页面采用 `getStaticProps` 返回 `{ props, revalidate: revalidateSeconds }` 的模式，并在 catch 中重新抛出错误以触发 ISR 失败。
- XML/RSS 类页面（`feed.tsx`、`sitemap.xml.tsx`）在 `getServerSideProps` 中手动设置 `Cache-Control` 与 `Content-Type` 响应头后直接 `res.write` + `res.end`，默认导出空组件。
- API 路由对非预期 HTTP 方法统一返回 405 状态码与 JSON 错误体，并在成功响应上显式设置 `Cache-Control` 缓存策略。
