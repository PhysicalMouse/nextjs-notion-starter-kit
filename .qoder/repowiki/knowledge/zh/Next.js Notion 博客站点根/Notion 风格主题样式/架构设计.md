本模块由三个并列的纯 CSS 文件组成，按职责分层：
- `global.css`：应用级基础样式（box-sizing、body 字体栈含 CJK 回退、滚动条、搜索输入框），定义 `--notion-font` 等根级变量。
- `notion.css`：针对 `.notion*` 类名的 react-notion-x 组件覆盖层，通过 CSS 自定义属性（如 `--notion-max-width`、`--fg-color`）和媒体查询适配响应式布局、画廊网格、书签、目录侧边栏等；使用 `.light-mode` / `.dark-mode` 双主题分支。
- `prism-theme.css`：在 `notion.css` 之后加载以利用级联优先级覆盖 prism-coy 默认主题，统一代码块与行内代码的配色。
依赖方向单向：三者均消费由上层注入的 CSS 变量（`--bg-color`、`--fg-color`、`--select-color-0` 等），不反向依赖任何 JS 或构建产物。
