模块以 `NotionPage.tsx` 为入口，聚合并定制 `react-notion-x` 的 `NotionRenderer`：通过 `notionRendererComponents` 注入自定义 Code/Collection/Equation/Pdf/Modal/Tweet/Header 等第三方块，并使用 `next/dynamic` + `ssr: false` 按需加载重型依赖（Prism 语法高亮、PDF、Modal），避免 SSR 水合差异。

- 页面骨架：`NotionPage` → `PageHead`（Next.js `<Head>` + JSON-LD 结构化数据）→ `NotionRenderer` → `Footer`（含可选 `Utterances` 评论）+ `PageAside`（预留侧栏扩展点）。
- 独立交互层：`SearchModal` 通过 `createPortal` 挂载到 `document.body`，从 `api.searchIndex` 拉取本地索引并按标签 AND 语义过滤；样式走 `SearchModal.module.css`。
- 外部集成：`Utterances` 动态注入 utteranc.es 脚本，随 theme prop 重建；`NotionPage` 通过 `useDarkMode` 与 `BodyClassName` 切换 `.dark-mode` / `.notion-lite` 全局类。
- 依赖方向：组件仅向上依赖 `@/lib/*`（config/types/map-image-url/search-notion），不反向引用其他业务模块；同级组件之间通过显式 import 组合，无共享状态。
