- 重型或易触发 SSR/CSR 水合差异的第三方库（Code、Collection、Pdf、Modal）统一通过 `next/dynamic` 延迟加载，并对需要纯客户端执行的组件设置 `{ ssr: false }`。
- CSS 采用 CSS Modules（`styles.module.css` 或同名 `*.module.css`），并通过 `classnames` 组合条件类名，而非内联 style 对象。
- 对外暴露的展示型组件使用具名函数导出，并在内部用 `React.memo` 包裹实现体（如 `FooterImpl`）以避免不必要的重渲染。
- 对 Notion 属性值进行定制时，遵循 `(props, defaultFn) => ...` 签名模式，在满足特定 schema 条件时返回自定义 JSX，否则回退到 `defaultFn()`。
