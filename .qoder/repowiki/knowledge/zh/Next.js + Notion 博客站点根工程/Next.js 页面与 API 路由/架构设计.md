模块以 Next.js Pages Router 约定组织：
- 根级页面：`index.tsx`（首页）与 `[pageId].tsx`（动态 Notion 页面），均通过 `getStaticProps` + `resolveNotionPage` 进行增量静态生成（ISR），并由 `getStaticPaths` 从 `getSiteMap()` 与 `pageUrlOverrides` 合并生成路径；渲染统一委托给 `@/components/NotionPage`。
- 应用壳 `_app.tsx` 注入全局样式（katex/prismjs/react-notion-x/global/notion/prism-theme）、初始化客户端 bootstrap，并挂载 Fathom、PostHog、Vercel Analytics/SpeedInsights、Microsoft Clarity 等埋点。
- 资源型页面 `feed.tsx`、`sitemap.xml.tsx`、`robots.txt.tsx` 使用 `getServerSideProps` 直接写响应头与 body，按 `host` 与 `siteMap.canonicalPageMap` 生成 RSS/站点地图/爬虫规则，并通过 `Cache-Control` 设置 CDN 缓存策略。
- `api/` 子目录为 Next.js API Routes：`search-notion.ts`、`search-index.ts`、`indexnow.ts` 处理搜索与索引请求；`social-image.tsx` 声明 `runtime = 'edge'`，使用 `next/og` 的 `ImageResponse` 在 Edge 运行时拉取字体并渲染 OG 图片。
- 依赖方向单向指向 `@/lib/*`（config、notion-api、resolve-notion-page、get-site-map、types 等），页面层不直接调用 Notion SDK，而是通过 lib 抽象。
