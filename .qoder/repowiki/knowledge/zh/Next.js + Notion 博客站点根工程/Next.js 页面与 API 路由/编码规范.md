- 动态 Notion 页面通过 `getStaticProps` 调用 `resolveNotionPage(domain, pageId)` 获取数据，并在 catch 中重新抛出错误以阻止发布失败版本。
- 需要服务端直写响应的页面（feed/sitemap/robots）使用 `getServerSideProps`，先校验 `req.method !== 'GET'` 返回 405，再手动设置 `Content-Type` 与 `Cache-Control` 后 `res.write(...).end()`。
- API Route 统一以默认导出函数接收 `(req: NextApiRequest, res: NextApiResponse)`，并对非预期方法返回 405 状态码。
- OG 图片接口通过 `export const runtime = 'edge'` 启用 Edge Runtime，并在运行时 fetch 字体以避免超过 Vercel 1MB 限制。
- 所有页面/接口都通过 `@/lib/config` 中的 `domain`/`host`/`revalidateSeconds` 等常量驱动行为，避免硬编码 URL 与缓存时长。
