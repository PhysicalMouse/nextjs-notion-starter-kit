模块由三个并列的 CSS 文件组成，按职责分层：
- `global.css`：页面级基础重置（box-sizing、body/html 边距、滚动条）与全局 CSS 变量（如 `--notion-font`），作为所有页面的根样式。
- `notion.css`：针对 `react-notion-x` 输出的 `.notion-*` 类进行主题化覆盖，包括画廊网格、封面图比例、标题目录侧栏、暗色模式、响应式断点等，是样式层的核心。
- `prism-theme.css`：仅覆盖 Prism 语法高亮的 token 颜色与代码块容器，依赖 `dark-mode` 类切换明暗主题。
三者之间无相互 import，依赖方向单向指向运行时注入的 DOM 类名（`.notion-*`、`.dark-mode`、`.token.*`），由上层应用负责引入顺序。
